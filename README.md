# Week 2 – Project 1: Footprinting & Reconnaissance

## Overview
This project was completed as part of my cybersecurity internship at Networkwalks IT Solutions & Training. The objective was to perform basic footprinting and reconnaissance using various information-gathering tools available in Kali Linux.

## Objective
To understand how reconnaissance tools can be used to collect publicly available information about a domain, examine DNS records, identify web technologies, inspect HTTP response headers, and investigate basic web security infrastructure.

## Tools Used
- **WHOIS** – Domain registration and ownership information.
- **WhatWeb** – Website technology fingerprinting.
- **Nslookup** – DNS lookups and domain resolution.
- **cURL** – HTTP response header inspection.
- **Wafw00f** – Web Application Firewall (WAF) detection.
- **DNS reconnaissance tool** – DNS-related information gathering.

## Practical Work
During this exercise, I used the above tools to perform different reconnaissance activities and observe the information each tool could reveal.

I captured screenshots of my terminal sessions to document the commands executed and their outputs as evidence of completing the practical exercise.

## Skills Practiced
- Basic footprinting and reconnaissance
- Domain information gathering
- DNS investigation
- Web technology identification
- HTTP header inspection
- Introduction to WAF detection
- Kali Linux command-line usage
- Technical documentation and evidence collection

## Evidence
Screenshots of the practical exercises are included in this repository to demonstrate the tools used and the results observed during the exercise.

## Learning Outcome
This project helped me understand how different reconnaissance tools serve different purposes in information gathering and how the information collected during reconnaissance can contribute to understanding a website's publicly exposed infrastructure.
